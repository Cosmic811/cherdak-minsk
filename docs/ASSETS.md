# Материалы сайта

AI-сгенерированные предметные сцены удалены из публичных ресурсов по запросу пользователя. Подтверждённых фотографий бара с разрешением на использование в проекте нет.

Hero — авторская архитектурная SVG-композиция, не изображение реального интерьера. Исходный концептуальный знак сохранён. Чтобы добавить настоящую галерею, заполните массив gallery в src/data.ts локальными фотографиями и подтвердите права для каждой записи (rightsConfirmed: true).
