# Чердак — презентационный прототип

React + TypeScript + Vite. Существующий проект, без новых зависимостей, фотографий и backend.

## Запуск

`npm install`, затем `npm run dev -- --port 5173`.

Локальный адрес: http://127.0.0.1:5173/.

`npm run build` проверяет TypeScript и создаёт `dist/`. Архив `cherdak-static.zip` содержит ту же статику. Предпросмотр: `npm run preview -- --port 4173`.

## Текущая итерация

Утверждённый hero сохранён. Ниже реализована композиционная система по приложенному пользователем референсу: правый светлый скат через переход «О баре», три зоны карты, две редакционные карточки афиши, inline-форма даты/гостей/времени и адресный финал.

Карта и события используют подтверждённые источники из `src/data.ts`, а при их отсутствии — отдельно помеченное презентационное содержание из `src/presentation.ts`. Реальных цен и дат в эскизах нет.

`EventCard.tsx` — общий компонент карточек; `BookingFields.tsx` — общие поля страницы и диалога. Выбор даты, гостей и времени синхронизирован. Форма не отправляет заявку и не создаёт бронь. Нативные диалоги, Escape, клавиатурный фокус и мобильная навигация сохранены.

Стили разделены: `src/style.css` — основа и hero; `src/editorial.css` — всё ниже него. Прежний menu.css заменён.

## Публикация

Основная площадка — GitHub Pages. Репозиторий: https://github.com/Cosmic811/cherdak-minsk. Адрес сайта: https://cosmic811.github.io/cherdak-minsk/.

Публикуется статическая сборка `dist/`; резервные копии, скриншоты, локальные зависимости и переменные окружения исключены из синхронизации исходников. Материалы для разработчика хранятся в `docs/`, вне публичных ресурсов сайта.

Ветка `main` хранит исходники, `gh-pages` — только содержимое готовой сборки `dist/` и `.nojekyll`. В настройках Pages выбраны `gh-pages` и `/(root)`. Относительные пути в Vite позволяют размещать сайт по адресу репозитория.

Для обновления выполните `npm run build`, обновите исходники в `main` и замените содержимое `gh-pages` файлами из `dist/`, сохранив `.nojekyll`. GitHub Pages опубликует изменения. Локальное редактирование само по себе не меняет публичную версию.
